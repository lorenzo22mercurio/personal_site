personal_site

Hi! I'm Lollo, a high school student who likes programming and wants to learn more.

This is my personal website, where I introduce myself and share what I'm learning.

I made this website using HTML, CSS, and JavaScript. I wanted to create something simple but nice, with a pixel art style inspired by old video games.

The website has a blue sky, pixel art mountains, falling snow, and a short introduction about me. It also shows the programming languages I know and the ones I want to learn.

I used HTML to create the content, CSS to style the page and add animations, and JavaScript to draw the background and create the falling snow.

I also used the Press Start 2P font to give the website a retro gaming style.

Right now, I know some C and HTML, but I'm still a beginner. In the future, I would like to learn Python, JavaScript, and Java.

I'm still learning and I know I have a lot to improve, but I want to keep practicing and making new projects.

To run the website, download or clone this repository and open index.html in your browser.

My goal is to improve my programming skills, try new things, and build more projects as I learn.

Thanks for checking out my website!
