About the Website

I made this website using HTML, CSS, and JavaScript. I wanted to create something simple but nice, with a pixel art style inspired by old video games.

The website has:

A snowy background with mountains and falling snow
A little pixel art penguin
A short introduction about me
A list of the languages I know and the ones I want to learn

HTML to create the content of the page
CSS to style the website
JavaScript to add animations and make the background move. I'm still a beginner with JavaScript, and I don't know how to use it very well yet, but I'm trying to learn more.

I also used the Press Start 2P font to give the website a retro gaming style.
